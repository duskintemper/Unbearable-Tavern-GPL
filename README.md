#  Unbearable-Tavern-GPL

**Unbearable Tavern**, released by [Dusk-In-Temper](https://dusk-in-temper.itch.io/), is a score attack mini-game where players serve customer whom are dungeon creatures as a werebear server. The game is developed using Godot Engine 4, and was developed as a challenge to learning using the engine in a month's period. 

This repository was created to share as an open-source resource of creating a similar gameplay. However, code architecture shown may not be the best practice due to the urgent and inexperience nature of the project's intention.

The `docs` folder contains licenses for the visual assets used for this project, as well as various community resources that has helped to make this project possible.

You can play a live version of the game on [here](https://dusk-in-temper.itch.io/unbearable-tavern).
